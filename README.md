# Pokédex React (versión sencilla)

Proyecto con React + Vite. Usa PokéAPI para mostrar Pokémon, imágenes, tipos, estadísticas y movimientos.

## Ejecutar

```bash
npm install
npm run dev
```

## Estructura

- `src/layout/`: Header, Footer y Layout.
- `src/components/`: tarjetas y ficha.
- `src/services/pokeapi.js`: peticiones `fetch` a PokéAPI.

Diseño simple para proyecto de clase; sin librerías de iconos ni imágenes inventadas.
